# Paperflite Assignment Submission

## Problems Implemented
1. Find single number using XOR
2. Remove K digits to get smallest number (Greedy + Stack)
3. Word Pattern matching using HashMap

## Language Used
Java

## How to Run

1. Navigate to src folder:
   cd src


2.Compile files:
javac *.java

3.Run each problem:

java ProblemOne
java ProblemTwo
java ProblemThree
